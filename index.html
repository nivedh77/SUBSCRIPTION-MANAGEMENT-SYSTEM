Native Subscription & Recurring Billing for Odoo 19

An enterprise-ready, fully native Odoo 19 Community module. Complete recurring billing cycles, automated customer invoicing via account.move, promotional discounts, real-time KPI analytics, and a self-service customer portal.

View on GitHub Explore Features

Comprehensive Feature Suite

Designed natively for Odoo 19 Community with clean ORM architecture and strict validation.

⚡

Flexible Subscription Plans

Configure Daily, Weekly, Monthly, and Yearly intervals with trial periods, base pricing, minimum quantity constraints, and auto-renewal toggling.

🧾

Automated Recurring Invoicing

Integrates directly with Odoo account.move. Automated daily billing cron, period duplicate protection, and accurate tax computation.

🏷️

Promotional Discounts

Support for percentage and fixed discount coupons with minimum spend thresholds and validity date windows applied to invoice totals.

💳

Accounting Payments & Due Tracking

Real-time synchronization with actual posted invoices: tracking total paid, outstanding due, and overdue receivables with payment status badges.

📊

Real Database KPI Dashboard

Zero fake or mock statistics. Direct PostgreSQL queries for total subscribers, active contracts, churned accounts, and received revenue.

🌐

Customer Self-Service Portal

Responsive portal interface at /my/subscriptions allowing customers to view contracts, download invoices, and request cancellations.

Quick Installation

Clone directly into your Odoo 19 custom addons directory.

1. Clone the repository:

git clone https://github.com/nivedh77/SUBSCRIPTION-MANAGEMENT-SYSTEM.git

2. Add to your odoo.conf addons_path and update apps:

addons_path = /path/to/odoo/addons,/path/to/SUBSCRIPTION-MANAGEMENT-SYSTEM
